# Charge Ghar Rental — Official Web Application

Official web portal and compliance system for **Charge Ghar Rental**, an automated portable power bank sharing service in Nepal operated by **Charge Ghar Pvt. Ltd.**

Designed in a high-contrast dark mode aesthetic and engineered to satisfy all **Google Play Store App Review, Data Safety & Account Deletion Policies**.

---

## ⚡ Key Features

- **Dark Mode UI**: Clean, high-contrast dark theme with electric charging neon accents.
- **Google Play Store Account Deletion Portal (`/delete-account`)**: Dedicated public web URL with In-App instructions, web request submission form with ticket generation, prerequisites checklist, and data retention breakdown.
- **Complete Legal Suite**:
  - [Terms and Conditions (`/terms`)](https://chargeghar.app/terms) (20 sections, Nepal law & arbitration)
  - [Privacy Policy (`/privacy`)](https://chargeghar.app/privacy) (13 sections, Privacy Act 2075 compliant)
  - [Rental Policy (`/rental-policy`)](https://chargeghar.app/rental-policy) (Fee schedule, deposits, lost penalties)
  - [About Us (`/about`)](https://chargeghar.app/about) (Mission, e-waste sustainability, app permissions)
  - [Contact Us (`/contact`)](https://chargeghar.app/contact) (Direct support channels, response SLAs)
- **Zero Play Store Violations**: Completely free from unsubstantiated promotional superlatives (no "Best", "Leading", "#1").

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (tested with Node.js 20 & 26)
- npm, yarn, or pnpm

### Installation
```bash
npm install
```

### Run Locally (Dev Server)
```bash
npm run dev
```
Open [http://localhost:3030](http://localhost:3030) in your browser.

### Production Build
```bash
npm run build
npm start
```
